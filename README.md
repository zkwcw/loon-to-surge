## 🔄 更新频率

- **自动更新**: 每天凌晨 2:00 (UTC+8)
- **手动触发**: 在 Actions 页面点击 'Run workflow'

## 📋 插件来源

所有插件来自 [可莉的Loon插件中心](https://hub.kelee.one/)
转换工具: [Script-Hub](https://github.com/Script-Hub-Org/Script-Hub)

- 如遇问题请查看原插件说明
