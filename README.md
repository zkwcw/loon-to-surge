## 🔄 更新频率

- **自动更新**: 每天凌晨 2:00 (本地定时任务)
- **来源**: [可莉的Loon插件中心](https://hub.kelee.one/)
- **转换工具**: [Script-Hub](https://github.com/Script-Hub-Org/Script-Hub)

## ⚠️ 注意事项

- 部分插件可能需要 MitM 或特定 Surge 版本
- 如遇问题请查看原插件说明
